# Остров далёких огней

Уютная 3D кооперативная игра для двоих, которая работает прямо в браузере на телефоне Android (Chrome), ставится как приложение (PWA) и может собираться в обычный `.apk` файл бесплатно через GitHub.

Никаких платных серверов, платных API и компьютера не нужно. Всё можно делать прямо с телефона.

---

## 1. Как поменять имена и тексты прямо с телефона

1. Открой свой репозиторий на сайте GitHub в браузере Chrome на телефоне.
2. Чтобы поменять имена (по умолчанию `Xyven` и `Wiyo`), нажми на файл `src/config.js`, затем на значок карандаша сверху справа:
   - `export const CREATOR_NAME = 'Xyven';`
   - `export const FRIEND_NAME = 'Wiyo';`
3. Чтобы поменять любые диалоги, задания или вставить свои 5 личных записок, открой файл `src/texts.ru.js` и нажми на карандаш.
4. Найди раздел `personalMessages` и вставь свой текст внутрь кавычек:
   ```js
   personalMessages: [
     'Первое сообщение у причала...',
     'Второе сообщение в лесу...',
     'Третье сообщение у озера...',
     'Четвёртое сообщение в руинах...',
     'Пятое сообщение под звёздами...',
   ],
   ```
5. Важно: не используй в текстах длинное или среднее тире, лучше ставь запятые, точки, двоеточия или троеточие.
6. Внизу страницы нажми зелёную кнопку **Commit changes**, чтобы сохранить изменения.

---

## 2. Как выложить игру на GitHub Pages (бесплатная ссылка для игры вдвоём)

1. Создай новый публичный репозиторий на GitHub и загрузи туда все файлы проекта (включая скрытую папку `.github/workflows/`).
2. На странице репозитория перейди во вкладку **Settings** (Настройки) сверху.
3. В меню выбери **Pages**.
4. В пункте **Source** выбери **GitHub Actions**.
5. Перейди во вкладку **Actions** сверху, выбери **Deploy to GitHub Pages** и нажми **Run workflow**.
6. Через 1 или 2 минуты появится зелёная галочка и готовая ссылка вида `https://твой-ник.github.io/название-репозитория/`.
7. Открой эту ссылку в Chrome на телефоне и отправь подруге. В меню Chrome можно нажать **Установить приложение**, чтобы игра появилась на рабочем столе телефона как отдельная программа.

## 3. Как бесплатно собрать `.apk` для Android через GitHub Actions

Компьютер и Termux не нужны, облако GitHub само соберёт Android-приложение:

1. Убедись, что в репозитории есть файл `.github/workflows/build-apk.yml` и `capacitor.config.json`.
2. Открой вкладку **Actions** в своём репозитории на GitHub.
3. Нажми слева/в списке на **Build Debug APK**.
4. Нажми **Run workflow** (или сборка запустится сама при каждом новом коммите в ветку `main`).
5. Подожди около 3 или 5 минут до зелёной галочки.
6. Нажми на завершённый запуск, пролистай в самый низ до раздела **Artifacts** и скачай `ostrov-dalekih-ogney-debug-apk`.
7. Распакуй скачанный `.zip` на телефоне и установи `app-debug.apk` (при первом запуске Android попросит разрешить установку из этого источника).

## 4. Как играть вдвоём и что делать, если мобильный интернет не соединяет

- Один игрок нажимает **Создать комнату** и получает код из 4 букв/цифр.
- Второй игрок нажимает **Войти по коду**, вводит эти 4 символа и жмёт **Подключиться**.
- Оба телефона соединяются напрямую через WebRTC (PeerJS + бесплатные STUN-серверы Google и Cloudflare).
- Для проверки механик без сети и без напарника выбери **Один на острове**, там рядом летает светящийся Эхо-огонёк, которого можно позвать на плиты и кристаллы.

### Запасной вариант через Firebase Realtime Database (если у оператора жёсткий NAT)

Иногда мобильный интернет одного из операторов блокирует прямое P2P-соединение. Тогда можно бесплатно подключить запасной канал через Firebase:

1. Зайди на `console.firebase.google.com` с телефона и создай бесплатный проект (тариф Spark, карта не нужна).
2. В левом меню открой **Build** -> **Realtime Database** -> **Create Database**.
3. Выбери ближайший регион и режим **Start in test mode** (тестовый режим).
4. Скопируй ссылку сверху базы (она выглядит так: `https://твой-проект-default-rtdb.europe-west1.firebasedatabase.app`).
5. Открой файл `src/firebaseConfig.js` в своём репозитории на GitHub, поставь `enabled: true` и вставь скопированную ссылку в `databaseURL`.
6. После сохранения на экране комнаты и входа появится рабочая кнопка **Запасной вход через Firebase**.
